1. Install 0.71.2 for exactly the four platforms above, using only the command
   printed by fleet preflight.
2. Pass the install audit for those same four expected platforms.
3. Run `npm ci` as the candidate preparation step.
4. Pass the manifest-ordered candidate checks: `npm test`, `npm run check`, and
   `npm run validate:metadata`.
5. Pass the repository's documented full local gate.
6. Publish one completion bundle whose work commit carries every managed
   change, so no follow-up commit and no force push is needed.

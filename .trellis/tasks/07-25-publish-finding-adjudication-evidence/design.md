# Finding Adjudication Evidence Publication Design

One canonical query/fold operation validates stored events and derives a
current view. Learning and effectiveness are allow-listed projections of that
view, not separate collectors.

Learning output groups valid underlying issues by normalized family while
retaining source reviewer identities. Invalid findings do not become preventive
guidance; duplicate findings contribute one issue. Effectiveness output keeps
same-plan exact-head pairs, trust level, and unresolved coverage.

Public GitHub summaries carry aggregate coverage and opaque receipt references.
Detailed bounded evidence is returned only to authorized trusted workflows.
